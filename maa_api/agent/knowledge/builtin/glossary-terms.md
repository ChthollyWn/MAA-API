未标注的是 PRTS 正式用词；标「社区」的是玩家说法，PRTS 没有词条，只用来理解用户在说什么，别当术语回复。同一俗称有时指多个东西（尤其「票」），拿不准就列候选并问一句。基础词（玉、石头、单抽券、黄票、绿票、理智药）见 `glossary`；这里只补它没写的，不写数值：要数字用 `get_prts_page` 查对应页面，抽数换算见 gacha-conversion，保底规则见 headhunt-rules。

## 货币与凭证
- 抽卡玉：合成玉的俗称，折抽数见 gacha-conversion。
- 石头、源石：至纯源石。可换合成玉、回理智或买时装，兑换率查 `get_prts_page(title="至纯源石")`。
- 黄票 = 高级凭证；绿票 = 资质凭证。高级凭证区换寻访凭证、十连券、加急许可、模组数据块；资质凭证区按周期重置库存，section 见 certificate-shops。
- 红票：采购凭证（社区）。采购凭证区不定期刷新，换芯片助剂、信物。
- 蓝票：通用凭证（社区）。来自中坚寻访与通用凭证区，用于通用凭证区兑换。
- 龙门币：精英化、升级的主货币。
- 赤金：贸易站卖出的硬通货，信用交易所也有。
- 井票、契约：寻访数据契约（社区）。限定寻访按抽数累积，攒够可在寻访数据契约交换所换当期限定 6★，门槛见 certificate-shops 的「寻访数据契约交换所」。
- 参数模型：寻访参数模型。契约过期后按比例转化而来，换 T4 及以下材料，比例见同页「寻访参数模型交换所」节。
- 情报凭证：复刻活动重复获得限定奖励时转化而来；情报凭证区（社区称紫票）只能靠复刻活动攒。

## 抽卡
- 单抽券 = 寻访凭证；十连券 = 十连寻访凭证；中坚券 = 中坚寻访凭证 / 十连中坚寻访凭证（只能抽中坚寻访）。
- 保底、概率提升：6★ 基础概率之上的递增机制，触发条件与增幅见 headhunt-rules，数值查 `get_prts_page(title="寻访规则")`。
- 大保底、选调：标准选调 / 定向选调。累计到阈值后下一个 6★ 必为 UP，阈值查 `寻访规则`。
- 井：限定寻访累计到一定抽数额外赠送当期限定干员（PRTS「必得赠送机制」），计数在寻访按钮左侧、要手动领；契约攒够也能直接兑换。
- 十连保底：新寻访特惠。每个新池开头一段抽数内必出 5★ 及以上，每池一次。
- 联动井：联动寻访累计到阈值必得联动 6★，阈值查 `寻访规则`。
- 池子：寻访。限定池不会复刻；标准、中坚、联动的保底计数互不通。当期有哪些池用 `get_gacha_pools` 查。

## 养成
- 精一、精二：精英化 1、精英化 2（PRTS 写作「精英1」「精英阶段2」）。
- 专一、专二、专三：技能专精 1/2/3 级（在训练室按等级逐段训练）。
- 模组：干员模组。精英阶段 2 等 1 以上、四星及以上才有，分基础模组与专属模组。
- 模组块：模组数据块。采购凭证区、高级凭证区、周常任务都给。
- 满潜：潜能满级。重复获得给信物，信物满了能换凭证。
- 信赖：信赖值。分信赖百分比与信赖点数，影响信赖加成和资料解锁。
- 芯片、芯片组：干员芯片 / 芯片组（芯片搜索 PR 产出，精英化要用）；胶水 = 芯片助剂（社区），精英化 2 要用。

## 基建
- 换班、轮换：基建进驻 / 队列轮换。控制中枢、产出设施、会客室、办公室可预设多套队列。
- 心情、体力：心情。耗尽会「注意力涣散」、加成失效，要送宿舍；数值查 `get_prts_page(title="罗德岛基建/宿舍")`。
- 收菜：领取制造站产物与贸易站订单。
- 无人机：有存量上限与自动充能，也能用理智或中枢技能补，数值查 `get_prts_page(title="无人机")`。
- 刷本俗称：钱本 = 货物运送 CE（龙门币）；经验本、狗粮本 = 战术演习 LS（作战记录）；红票本 = 粉碎防御 AP（采购凭证）。

## 玩法与日常
- 剿灭：剿灭作战。当期/长期委托给合成玉，剿灭战模拟不给；每周有上限，超出改成返还理智。
- 公招：公开招募。消耗招聘许可，标签可选多个（有数量上限），时长决定稀有度下限。
- 加急：加急许可。立刻完成一次公开招募。
- 突袭：关卡的高难模式（PRTS 在评价星数里写作「突袭/遭遇战」）。
- 代理、代理指挥：游戏按通关记录自动复现上次打法的功能（见 stage-rules）；剿灭与保全另有消耗代理卡的「全权委托代理指挥」。
- 挂机：把流水线交给本服务或游戏自动跑。
- 理智药：理智药剂 / 应急理智浓缩液。回复理智，注意过期时间。
- 碎石：用至纯源石回理智，会花掉付费货币，兑换率见 currency-sources。
- 肉鸽：集成战略；生息演算；危机合约、矢量突破属周期挑战。
- 事相结晶：解锁曲谱里没体验过的插曲/别传关卡，按周补发获取机会、有存量上限，细节查 `get_prts_page(title="事相结晶")`。

## 材料
- 紫材：T4 紫色材料（PRTS 用词）。高级凭证区、寻访参数模型可换。
- 蓝材、金材：社区按图标底色叫的档位（大致对应 T3 / T5），PRTS 只对 T4 用了「紫色材料」的写法。
- 土：固源岩系列。源岩 → 固源岩 → 固源岩组 → 提纯源岩，四档。
- 铁、酮、糖、酯、装置：同一系列的统称，后面加「组 / 块 / 聚块」表示更高档位。
