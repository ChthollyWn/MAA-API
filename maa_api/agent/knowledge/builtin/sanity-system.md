## 基本概念
- 理智是刷图消耗的「体力」，不在仓库里显示；首页「终端 TERMINAL」按钮和作战关卡选择右上角都能随时看到当前值与上限（位置见 screen-home）。
- 每关消耗各不相同，回答具体数值前先 `get_stage("<关卡代号>")` 读 `sanity` 字段，不要凭记忆说大概值。
- 理智有持有上限，上限跟随博士声望等级变动。**当前上限问用户**：让他看游戏内关卡选择右上角读到的值，或用 `get_screenshot` 读，不要拿记忆里的旧值纠正他。上限的具体规则与历史调整见 `get_prts_page(title="理智")`。

## 自然恢复
- 自然恢复的速率见 `get_prts_page(title="理智")`（该页有「理智回复方式」一节），不要凭记忆报。
- 达到理智上限后停止自然恢复：满理智期间不累积、不清算，多出来的时间直接损失。
- 因此规划时先算「离上限还差多少、要等多久」，再决定是现在刷还是先吃药。

## 理智回复道具
- 消耗药剂/食物后立刻回复对应数量。**每种道具的回量用 `get_item("<道具名>")` 现查**（道具一览见 `get_prts_page(title="道具一览")`）；查不到时不要编数值。
- 因理智不足而补充时，游戏按可回复的理智量依序自动选择即将消耗的物品，直到达到需求——先消耗哪个由游戏决定，不要替用户假设「先喝小样」。
- 手动回复（药剂/食物/源石）有溢出上限：如果这次回复会溢出上限，操作会被取消，道具也不消耗。上限是多少见 `get_prts_page(title="理智")`，不要凭记忆报。
- 药剂/食物会过期：到期会被自动强制使用，回复量同样受溢出上限约束。

## 用至纯源石回复理智
- 至纯源石回复理智的回量是固定值，具体数值见 `get_prts_page(title="至纯源石")`；不要报记忆里的旧机制（它曾经按当前上限计算，现已改为固定值）。
- 同样受溢出上限约束，会溢出时无法使用。
- 在 MAA 里这就是「碎石」，即 Fight 任务的 `stone` 参数。它消耗付费货币，属于消耗类参数，提交前必须让用户确认（术语见 glossary）。

## 理智不足时的表现
- 理智不够支付关卡消耗时不会直接开战，而是走补充理智的流程；PRTS 理智页原文：「因理智不足而通过该方法补充理智时，按可回复的理智量依序自动选择即将消耗的物品，直至达到理智需求」。
- MAA 内核任务表里另有一条注记：理智不足时会停在吃药界面明显更久，理智足够时很快就进入下一步。
- 对应到本服务：Fight 的 `medicine`（最多吃几个理智药）与 `stone`（最多碎几颗源石）都是「最多允许用几个」，默认 0 表示不吃药也不碎石。参数为 0 时如果理智不够，任务只能停在补充界面等人处理。
- `Fight.expiring_medicine` 自内核 v6.8.0 起**已弃用**（内核改用 `medicine_expire_days`），本服务只为兼容旧提交保留，**不要主动填**。
- 回答「还能打几次」用 ⌊当前理智 ÷ 单次作战消耗⌋（单次消耗来自 `get_stage` 的 `sanity`），并把自然恢复另算；不要把恢复量提前算进可打次数里告诉用户。
