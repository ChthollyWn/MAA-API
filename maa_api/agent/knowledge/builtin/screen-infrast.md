**本条目不给像素或百分比坐标**：游戏界面的具体布局在 PRTS 上没有依据，写数字会点错。下面只给相对位置，用之前先 get_screenshot，按「像素 = 比例 × 截图 width / height」量取，并把量到的值写进回复。

## 大致位置
- 从首页进入基建：基建入口在首页下部的功能按钮里（和终端、仓库等入口同一片区域，仓库在右下，见 screen-home）。走 Recruit/Infrast 这类任务时由内核自己进出，手动操作才需要找入口。
- 基建总览是整屏俯视图：左侧或上方有楼层/区域切换（B1、B2、B3、1F 之类），上下或左右拖动可以平移视野。每个房间是一块方块，方块上能看到设施图标、进驻干员头像，以及状态标识。
- 点房间方块打开设施详情面板：面板里是进驻信息、进驻人员、产出数据，底部或右侧有操作按钮。
- 无人机的两个入口：发电站详情里的充能信息；控制中枢解锁后，制造站/贸易站详情里多出「无人机协助」按钮。
- 设施详情的产出数据（位置在面板中部）：制造站是仓库容量 X/Y、生产力、已节省；贸易站是订单列表、获取订单效率、心情消耗/时、干员信息倒计时；发电站是提供电力、充能速度；办公室是人力资源余量 X/Y、联络进度、联络剩余时间；宿舍是氛围、心情恢复/时。
- 干员进驻与撤下：设施详情里的「进驻信息」进入角色配置界面，可直接选人进驻、撤出并调整顺序；撤出支持按位撤出或全部撤出，按位撤出不影响其他干员的位置。批量操作在「进驻总览」（队列轮换、干员休整）。

## 心情显示在哪里
- 角色配置界面与进驻总览里，每个干员带标识状态：工作中、空闲中、休息中（宿舍）、锁定中（宿舍锁定区）、训练中（训练室专精）、注意力涣散（心情为 0，红色）。这是判断要不要换班最直接的依据。
- 设施详情里的「心情消耗/时」只反映该设施的基础消耗与减免，不包含干员自身技能影响；贸易站/制造站的「干员信息倒计时」才是「还有多久会进入注意力涣散」。
- 宿舍详情里的「心情恢复/时」分两段显示（宿舍等级部分 + 氛围与技能部分），氛围值也在同一面板。

## 需要截图确认的内容
- 基建总览里各楼层与房间方块的实际占屏比例、楼层切换控件的位置。
- 设施详情面板与角色配置界面的按钮位置（进驻信息、按位撤出、队列轮换、干员休整）。
- 心情条的样式与位置（头像下方的细条还是侧边标识），以及注意力涣散标识的实际颜色与文案。
- 不同客户端版本、不同首页主题下文案与图标可能变化，以截图上的实际文字为准。

## 操作注意
- 点击属于原子操作，第一次会弹出会话授权确认，先告诉用户。
- 每次点击后重新截图确认状态变化，不要连点；换班会重排岗位，中途连点容易点错设施。
- 只想看不想动：截图后先在回复里写出设施名、进驻干员和心情状态，再决定下一步。
