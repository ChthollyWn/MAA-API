## 它是什么
- 剿灭作战是每周稳定的合成玉来源。每张图有固定的敌人总数，报酬按**单局击溃人数**分档给玉，击溃越多档位越高。
- **只有【长期剿灭委托】和正在开放中的【剿灭委托】给合成玉；【剿灭战模拟】不给合成玉。**
- 击溃人数越高，拿到的玉越多、「理智返还」越少：如果这一局能拿的玉会超过本周上限，超出部分按击溃人数与奖励档位折算成**返还理智**。
- 敌人总数用 `get_stage(stage=…, include=["enemies"])` 查；分档节点与各档产出查 `get_prts_page(title="关卡一览/常态事务")` 的「剿灭作战」节。三张长期图里单局产出最高的是 `炎国 龙门市区`，想省次数优先打它。

## 地图与理智
- **长期剿灭委托**是常驻的几张图，按开放顺序解锁：乌萨斯 切尔诺伯格、炎国 龙门外环、炎国 龙门市区。要先通关前一张才解锁下一张，评价达标即可，不必满星；解锁条件与消耗看游戏内界面。
- 作战消耗、敌人数量与机制不要背：`get_stage(stage=…, include=["basic","enemies"])` 收中文关卡名、代号或 stageId；机制读 PRTS 页 `乌萨斯 切尔诺伯格` / `炎国 龙门外环` / `炎国 龙门市区`。
- **当期剿灭委托**：限时轮换，会换图。**当前是哪张、何时结束用 `get_activity_stages` 现查。**
- **剿灭战模拟**：已经结束的委托会变成模拟状态。可以打它拿一次性的作战进度奖励，但**不产合成玉，也不能用全权委托**（常规代理作战不受影响）。

## 每周上限怎么涨
- 每周可获得的合成玉有上限，超过初始上限的部分只能靠**一次性历练任务**提升。任务入口在地图界面左下角的合成玉进度处，界面上能看到当前上限与已获得进度。
- 历练任务的条件是「在指定地图单局打到某个击溃数」，每完成一档加一点上限，全部做完才是满上限。档位与增量同在 `关卡一览/常态事务` 的「剿灭作战」节。
- 用户说「上限差一点点到不了满」，先让他核对**当期剿灭委托**那一档历练任务是不是还没做——当期委托轮换后这一档最容易漏。
- 每周刷新在周一凌晨，具体时刻以游戏内为准。

## 首通与作战进度奖励（一次性）
- 每张剿灭图有一组作战进度节点（按击溃人数分档），**每个节点只给一次**，内容是资质凭证、高级凭证、作战记录、龙门币；档位要求与奖励明细同在 `关卡一览/常态事务` 的「剿灭作战」节。
- 长期委托的进度奖励里带「每周报酬上限提升」，这是提升周上限的唯一途径；一次性奖励吃完后，剿灭只剩「每周领合成玉」这一项长期收益。

## 代理指挥与扫荡（全权委托）
- 通关一次即可解锁该图代理指挥（条件以游戏内为准）。
- **全权委托**（俗称扫荡）：消耗一张【常态事务代理卡】和理智，跳过作战直接结算。报酬与理智消耗都按该图**无助战**记录里的**最高歼灭数**结算，且**不加任何干员信赖值**。
- 代理卡从**每日任务**拿（倒数第二层）。每张卡有领取后的过期时间，执行时优先消耗最早过期的；剩余有效期看游戏内道具详情。
- 解锁前提：该图有**无助战**、击溃数不为零的战绩记录，且当前不是【剿灭战模拟】。所以**新剿灭图还是要自己先打一遍**。
- 这次全权委托能拿的玉为零时无法使用（例如该图已不给玉）。

## 什么时候该打
- 新手顺序：先按 切尔诺伯格 → 龙门外环 → 龙门市区 打完长期委托，拿满一次性奖励并把周上限提上去，再打当期委托和剿灭战模拟。
- 每周目标是把上限打满：日常周常的合成玉 + 剿灭满上限（见 currency-sources）。打满后按 PRTS 建议改打当期剿灭委托——单局产出更高、需要的作战次数更少。
- 不想手动打就用全权委托扫荡已有满击溃、无助战记录的图；打不满也给玉，只是拿不满上限。
- 剿灭作战的「报酬」栏是合成玉，常规掉落只有作战记录：切尔诺伯格掉基础作战记录，龙门外环与龙门市区掉初级作战记录。想刷养成材料不要来剿灭，它的价值就在每周那笔玉。
- 这些机制是**国服数据**，外服可能尚未实装或数值不同，外服用户以游戏内界面为准。
