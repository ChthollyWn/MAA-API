## 进入与分类
- 商店是首页的「采购中心」。PRTS 把采购中心分成这几块：可露希尔推荐、源石交易所（充值）、组合包、时装商店、凭证交易所、家具商店、信用交易所（社区常叫「信用商店」）。
- 分类按钮在采购中心界面上方或左侧，具体比例位置**需截图确认**；按文字找「信用交易所」「凭证交易所」比按坐标点可靠。
- 凭证交易所内部又分：资质凭证区、高级凭证区、通用凭证区、采购凭证区，以及限定池期间的寻访数据契约交换所、寻访参数模型交换所，和复刻活动用的情报凭证区。各区卖什么、什么时候刷新、凭证怎么来，见 certificate-shops。
- 余额显示在对应区块的界面里，**需截图确认**；拿不准就先按 screen-home 读首页顶栏，或按 screen-depot 数仓库里的凭证。

## 别买错货币
- 时装商店：至纯源石。家具商店：家具零件，也可以用至纯源石。
- 信用交易所：信用点。凭证交易所各区：对应的凭证（资质/高级/通用/采购/情报凭证）。
- 源石交易所是充值入口，不是拿游戏内货币换东西的地方——用户说「去商店买东西」时要先分清是哪个区。

## 信用交易所
- 物资每天刷新，件数与信用上限见 PRTS「采购中心」；每天凌晨 4:00 会把超出上限的部分清空，所以信用满了要当天花掉。
- 折扣只出现在少数商品上（折扣档位与适用商品见 PRTS「采购中心」）。折扣大的排在列表前面。
- 有「累计信用消费解锁干员合同」的机制，合同刷新在第一个栏位。

## 交给本服务时
- Mall 任务对应的是「获取信用及购物」，也就是信用交易所这一套（领取信用 + 按清单购物），不代替用户在凭证交易所里花凭证。
- Mall 的 `buy_first` / `blacklist` 填商品名（例如「招聘许可」「加急许可」「家具零件」）；`shopping` 属于消耗类参数，第一次提交会弹会话授权确认，先告诉用户。
- 与版本绑定的当期商品和价格不要凭记忆报，让用户看游戏内，或由用户点名要买什么。
