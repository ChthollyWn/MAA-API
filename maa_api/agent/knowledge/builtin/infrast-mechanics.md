具体数值（电力、建造上限、配方耗时与原料、订单档位、心情与氛围公式、无人机充能）一律用 `get_prts_page` 现查，这里只讲机制。常用页：`罗德岛基建` 及子页 `罗德岛基建/控制中枢`、`/发电站`、`/制造站`、`/贸易站`、`/加工站`、`/训练室`、`/宿舍`、`/办公室`，独立页 `会客室`、`无人机`；基建在**通关主题曲前置章节后解锁**。

## 设施分类与各自作用
- 工作区：控制中枢、发电站、制造站、贸易站、会客室、加工站、办公室、训练室。
- 非工作区：只有宿舍。特殊类：活动室（引导干员行动、拿活动室信赖）。
- 控制中枢：等级决定区域开放程度与部分设施的最高等级；进驻干员减少整个基建的工作心情消耗；可任命「基建副手」每日获得额外信赖（不算进驻）。
- 发电站：提供全基建的电力，电力不足就不能继续建造/升级；进驻干员提升无人机充能速度。
- 制造站：制造基础资源；进驻干员才能启动，并提供制造速度、心情减免。
- 贸易站：与外界交易换报酬；进驻干员获取订单，并提供订单获取速度、心情减免。
- 会客室：建成后解锁好友与线索功能；进驻干员加速线索收集，并每日获得额外线索。
- 加工站：建成后可加工高级材料；进驻干员使加工时概率获得副产物。
- 办公室：建成后获得额外的公开招募栏位；进驻干员获得公开招募标签的刷新次数。
- 训练室：为精英 2 阶段且技能等级达标的干员提供技能专精；训练位指定专精计划，协助位缩短所需时间。
- 宿舍：进驻后能恢复干员心情（未进驻的干员不会自己回心情）。

## 制造站配方
- 配方分作战记录、赤金、双芯片、源石碎片几类；各自要求的制造站等级、原料与份数、基础耗时用 `get_prts_page(title="罗德岛基建/制造站")` 现查，双芯片另需芯片助剂（所有职业同规则）。
- 源石碎片是搓玉的前段：原料二选一（固源岩或装置）并**额外消耗龙门币**，配方与代价见 `get_item(name="源石碎片")`。
- 机制要点：
  - 启动条件：不指定制造方案和份数、或不进驻干员，就不会开始制造。
  - 产物归属：**未收取的产品不进道具仓库**，不能按仓库数量判断原料有没有被消耗。
  - 原料扣除：需要原料的方案在选定时就扣原料，产品完成前不算消耗，下调数量会归还。
  - 份数：可设置份数受原料数量限制，并有上限。
  - 仓库容量与进驻上限随等级提高；每名非涣散干员都提供一份固定生产力加成；「自动补货」在【游戏设置 - 提醒 - 自动补货】里开关。

## 贸易站订单
- 谈判策略「龙门商法」出贵金属订单（赤金订单）：交赤金换龙门币，站等级越高，单笔要求的赤金与龙门币越多、耗时越长。各档数值见 `get_prts_page(title="罗德岛基建/贸易站")`，折算收益用 `get_item(name="赤金")`。
- 谈判策略「开采协力」出源石订单：需要制造站达到一定等级，交源石碎片换合成玉。
- 赤金档位不固定：站等级与档位共同决定各档出现概率，部分后勤技能（裁缝、手工艺品、鉴定师类）会改写分布，让高赤金订单变多。
- 订单上限与进驻上限随站等级提高；订单获取效率有基础值，另加每名工作状态干员的固定加成。
- **订单在开始计时那一刻就定了**：改谈判策略只对下一次获取生效。贸易站干员信息会显示「进入涣散状态的理论所需时间」。
- 找谁进驻用 `get_building_skills(room="贸易站")` 或 `get_infrast_candidates` 现算，别凭记忆点名；基建技能详情用 `get_operator(name=…, sections=["building"])` 查。

## 无人机
- 用途：设施建造/升级；控制中枢到一定等级后解锁「无人机协助」，可消耗无人机加速制造站制造与贸易站订单获取。
- 每架无人机的加速量按基础耗时折算，具体比例见 `get_prts_page(title="无人机")`。
- 充能速度只受发电站进驻干员加成影响；存量有上限，清理区域可以提升上限。
- 充能不会因到上限而停止，**超出上限的部分被丢弃**（发电站永远不会「充满停机」），满了尽快用掉。
- 控制中枢到更高等级后解锁「急速充能」：用理智直接充能，但受上限限制（接近上限时无法急速充能）。

## 干员心情（最容易被忽略的一块）
- **未进驻的干员心情不变、不会自己恢复**——回心情得送进宿舍（个别后勤技能能给同设施干员少量回复）。
- 进驻后的标识状态：工作中（心情在掉）、空闲中（心情不再下降，加工站干员和停机设施里的干员通常是这个）、休息中（心情在涨，通常是宿舍）。进驻宿舍锁定位置的显示「锁定中」，在训练室正在专精的显示「训练中」。
- **心情耗尽是注意力涣散**：无论是否进驻，后勤技能与基础效率等大部分加成都会失效；涣散干员不算「处于工作状态」，不计入制造站生产力、发电站充能等加成。
- 降低消耗：控制中枢每名工作状态干员提供一份全员心情消耗减免（作用于所有工作区，不含中枢自身与加工站这类瞬时结算设施）；制造站/贸易站进驻人数越多，人均基础消耗越低。系数见 `罗德岛基建/控制中枢` 与对应设施页，且不含干员后勤技能效果。

## 宿舍与氛围值
- 心情恢复速度 = 宿舍等级部分 + 氛围与技能部分，等级与氛围越高恢复越快；公式见 `get_prts_page(title="罗德岛基建/宿舍")`。
- 氛围值有等级上限，摆家具提升氛围，氛围越高回心情越快。
- 进驻总览的「干员休整」会把**未进驻且心情未满**的干员按心情比例由低到高填进宿舍空位，优先氛围高、楼层靠上、位置靠前的宿舍。
- 工作区可设「队列」（每个设施存若干套预设），用「队列轮换」批量换班；快速切换顺序：都不在训练室训练位 ＞ 总心情比例最高 ＞ 队列序号靠前。预设队列读写用 `list_infrast_plans` / `set_infrast_plan`。

## 会客室、加工站、办公室、训练室的补充
- 会客室：只有进驻干员时才按日发线索；线索有存量上限、生成有基础耗时；宿舍总氛围、进驻干员稀有度/精英阶段、会客室等级都提供搜集速度加成；集齐后可开启线索交流。数值见 `get_prts_page(title="会客室")`。
- 加工站：**不进驻干员就完全拿不到副产物**；进驻后每次加工瞬时扣掉配方要求的心情、按配方基础概率拿副产物。由于是瞬时结算，加工站干员**不享受中枢的心情减免**；涣散时同样拿不到副产物。各配方概率见 `罗德岛基建/加工站`。
- 办公室：等级决定公开招募位数量；进驻后联络次数开始恢复（有间隔与上限，非涣散时另有加成），到上限后进驻干员暂停工作、不再消耗心情。数值见 `罗德岛基建/办公室`。
- 训练室：训练位干员按指定计划专精，协助位缩短专精用时；训练位有干员在训练时，该干员无法被队列快速切换应用。

## 常见坑
- 以为干员放着不管会自己回心情：未进驻干员心情不变。
- 心情耗尽的干员留在岗位等于白占位（技能与效率加成失效），换班优先处理。
- 改了谈判策略却以为当前订单会变：订单在计时开始时就定了。
- 用仓库材料数量判断制造站有没有在消耗原料：它的暂存仓库不算道具仓库。
- 无人机满了不管：超出上限的充能被直接丢弃。
- 加工站图省事不进驻干员：副产物拿不到。
