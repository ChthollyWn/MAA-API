## 入口与界面锚点
- 首页有「干员寻访」按钮，进寻访界面点它。**限定寻访的赠送次数攒够时，这个按钮上会出现金黄色的 FREE 标志**（PRTS 原文记载，可以当「有东西可领」的信号）。
- 限定寻访的「必得赠送」计数显示在寻访界面**寻访按钮的左侧**，达到条件后要手动点领取（限定当期有效，关池后只能等邮件补发）。
- 卡池列表、单抽/十连按钮、当前合成玉与寻访凭证的显示位置，PRTS 没有记载，**需截图确认**。点之前先看清按钮上的数字，别把十连当单抽点。
- 抽卡本身是消耗行为，**不要替用户点**。要报数量就按 screen-home 读首页货币、按 screen-depot 读仓库凭证，或让用户在界面上自己念数。

## 先确认进的是哪个池
- 标准寻访（常驻每两周轮换、限时随活动开，可能随活动复刻或返场）、中坚寻访（2023-04-06 起最早的一批 6★/5★ 单独成池，走「中坚获取规则」）、限定寻访（春节/庆典/夏季三类）、特殊寻访（新人特惠、跨年欢庆、新年特别十连、联动、归航）。
- 概率、保底、选调、井的完整算法见 headhunt-rules。这里只强调一条**会影响回答**的：标准、限定、联动各池的计数**互不继承**，所以必须先问清用户抽的是哪一类池，再谈「还差多少抽保底」。

## 结果页
- 抽完会进结果页，显示本次抽到的干员；翻页与关闭按钮的位置 PRTS 没有记载，**需截图确认**。
- 用户问「刚才出了什么」「寻访记录怎么看」时，画面上的事让他自己看，PRTS 查不到的入口位置不要凭印象指路。
