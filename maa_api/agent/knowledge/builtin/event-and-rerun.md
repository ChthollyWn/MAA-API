## 一次活动长什么样
以 SideStory 为例，一次活动由四块组成，公告里就是这么写的：**活动关卡作战 + 活动任务/收集玩法 + 活动商店 + 活动奖励（活动干员、家具、时装等）**；同期还会开一个限时寻访放新干员。
- 解锁条件一般是通关某条主线关卡，具体是哪一关看当期公告，不满足就进不去。
- 活动代币只在这期活动里通用：关卡和任务产出代币，代币在活动商店里换东西。商店奖励通常含活动干员及其信物、家具、寻访凭证、时装与各类养成材料。
- **活动关卡是分阶段开放的**：公告会写「第一段 / 第二段 / 第三段」，逐段放开，末段临近活动结束时才开。所以「今天能不能打后面的关卡」取决于当前处在第几段，不要假设全开。
- 活动结束后还会保留一段兑换期（兑换结束时间晚于活动结束时间），过期就真的换不了了。
- 故事集（社区也叫 Vignette）：同样有关卡、代币、兑换和活动干员，但体量小、开放时间短。PRTS 现在把各种形式统一收进【曲谱】，按故事线分成【乐章】，统一叫【章节】。

## 复刻（同一期活动第二次开）
复刻不是「重开一遍」，规则和首开明显不同：
- **关卡进度和首次掉落进度继承上一次**：拿过的首通/首次掉落奖励不会再给；复刻一开始就开放包括 EX 在内的所有关卡，但没打过的新玩家仍要按顺序解锁。
- **活动任务的完成进度不继承**，所有任务要重新完成。
- **无法重复获得的那部分奖励，在重复获得时会按比例转成情报凭证**（典型是干员时装、家具），情报凭证在采购中心的情报凭证区消费，比例用 `get_prts_page(title="采购中心/凭证交易所")` 取页内**情报凭证区**节现查（该页正文按 section 分节，**节名随线上页面变动**：先不带 `section` 读一次，按关键词从返回的 `sections` 里挑中那一节，再带 `section` 取正文）。
- 商店和奖励结构会被改动（例如去掉无限池、改有限池与里程碑奖励、取消活动限定日常任务），开放时间也明显比首开短。
- 活动干员的获取渠道仍在活动任务/活动商店里，复刻期间商店重新开放，重复拿到的部分按上一条转凭证；具体以当期公告为准。
- 不同活动的复刻细节不一样，回答时以当期公告和游戏内为准，不要拿旧活动的复刻说明套新活动。

## 活动结束、被收进常驻之后
- 【插曲】= 和主线有紧密联系的 SideStory，首次开放结束后**立刻**收录；【别传】= 其它的 SideStory，**复刻结束后**才收录。收录进度与各章节的收录状态查 `get_prts_page(title="关卡一览/曲谱")`。
- 收录后会删掉配套的商店、任务、限定奖励与代币掉落，部分材料掉落（别传还包括理智消耗）和原活动不同；蚀刻章在非活动期间拿不到，复刻结束后永久绝版。
- 没体验过的插曲/别传要消耗事相结晶解锁；事相结晶每周补一次获取机会、签到自动消耗，并有存量上限（声望更高时上限提高）。节奏与上限数值查 `get_prts_page(title="事相结晶")`，别凭记忆报。
- 开过「记录修复」的活动例外：完成该系列关卡（不含剧情、教程关）积累评价星数——2 星/3 星都算，突袭/遭遇战记 4 星——可以拿回该活动的限定奖励。

## 用本服务刷活动
- 当期是哪个活动、这一期有哪些关卡代号，用 `get_activity_stages` 查（数据来自本机活动资源）；`resolve_stage` 只校验内核认不认这一关。活动关卡的代号体系见 `activity-stage-codes`。
- Fight 的 `stage`：当期 SideStory 后半段的 EX 关要写完整关卡编号；普通活动关按公告里的关卡代号写。
- 提交前先确认这一段已经开放（见上），后面的关卡没开就等着，或先刷前面的代币关。
- 用户问活动时间、当期商店内容这类会变的信息时，答「以游戏内公告为准」，不要凭记忆报日期。

## 优先刷什么
下面是社区通行的取舍顺序，不是 PRTS 规则，用户有自己的偏好时让他决定：
1. 先把能打的活动关推到首通，拿首通源石与一次性奖励（这部分复刻不再给，过期作废）。
2. 代币优先换**不可替代**的东西：活动干员及其信物、限定家具、时装、寻访凭证。
3. 其次换模组养成材料和高级素材，最后才是龙门币、作战记录这类平时也能刷的。
4. 商店快关时提醒用户把代币花掉——兑换期一过就用不了了。
