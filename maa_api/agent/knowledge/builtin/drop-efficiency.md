## 掉落是概率判定，不是固定值
- 关卡页「常规掉落」标的是掉率档位，不是确定值。档位名称为：固定掉落 / 小概率 / 概率 / 大概率 / 罕见（例：1-7「固源岩：固定掉落」）。
- 「固定掉落」可理解为该关每次通关都给；「小概率」「大概率」只是档位名称，不要自己折算成百分比。
- 通关还会从该关的「额外物资」池里按概率给一份低级材料，也要算进总收益，否则会低估某些关卡。
- 默认前提是 3 星稳定通关：非三星时素材奖励下降，极端情况下一个都不给。
- 「首次掉落」（干员、家具、首通源石）只拿一次，比较长期收益时必须排除。
- 现查口径：`get_stage(stage=…, include=["basic","drops"])` 给作战消耗与该关掉落，`get_drop_rates(item=…或 stage=…)` 给企鹅物流统计的掉率、样本数与单件期望理智，`get_item(name=…)` 给该材料掉率靠前的关卡。

## 怎么比较两张图的收益
1. 把两边折算到「每点理智能拿到多少目标材料」：单次期望掉落 = Σ(单次掉落数量 × 掉率)，再除以该关的作战消耗。
2. 只比「单次掉落量」会得出错误结论：理智消耗、额外物资、副产物都可能逆转结论。
3. 主产物期望接近时，选副产物也对用户有用的那张图。
4. 数据来源要交代清楚：PRTS 掉落表由企鹅物流统计提供，页面提示存在统计区间、数据可能已过期；`get_drop_rates` 会把样本不足的条目标注出来并排在后面。引用掉率要带来源与时间。

## 常驻图与活动图怎么选
- 限时活动期间优先活动图：SideStory 主线关的最后几关掉率明显高于主线，是刷蓝色材料的主力；活动关还给代币，可换商店物品。
- 活动结束后这些关卡收进曲谱的插曲/别传，届时删掉商店、任务、限定奖励与代币掉落，并调整材料掉落与理智消耗（通常调低）。除首通源石外，不建议把理智长期投进常驻插曲/别传（收录规则见 event-and-rerun）。
- 龙门币有专门的资源收集关卡，主线图产出明显更低，别拿主线刷龙门币（见 currency-sources）。
- 资源收集与芯片搜索关每周固定开放日，推荐前先确认今天开不开。
- 有一类别传关卡**不消耗理智**，适合刷通关、歼灭数类任务：`get_stage(stage=…, include=["basic"])` 看作战消耗就能确认；火蓝之心系列的 OF-4 与 OF-8 常被点名。

## 常驻最优图的判断
- 不要凭记忆点名「最优图」，也不报具体掉率百分比（除非用户给了来源或本次确实查到带区间的统计）。要么引用 PRTS / 游戏内的依据，要么用本服务实际刷到的数据（见 playbook-drop-lookup）。
- 稳定例子：搓玉原料以 1-7 刷固源岩为推荐做法。其余关卡优劣随版本与掉落调整变化，以游戏内与 PRTS 材料页为准。

## 不要做的事
- 不用一次作战的结果推断掉率。
- 不要把本服务的历史掉落样本（`get_drop_stats`）当成官方掉率，它只反映刷过的记录。
