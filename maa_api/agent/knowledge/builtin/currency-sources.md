## 刷新节奏
- 国服的日常刷新在每天凌晨，每日/每周任务与剿灭作战都以此为界；每周刷新在周一。具体时刻以游戏内为准。

## 合成玉：每周固定收入
- **每日任务**与**每周任务**各给一笔固定合成玉，是最稳的周收入；**月卡**额外给一份每日配给，当日不领会作废，叠加后周收入更高。
- **剿灭作战**：每周获取有上限，上限靠一次性历练任务提升，机制见 annihilation-weekly。
- 想知道「每周刷满能攒多少」，别背数：日常周常的数额查 `get_prts_page(title="合成玉")`，剿灭部分的档位查 `get_prts_page(title="关卡一览/常态事务")` 的「剿灭作战」节，两处相加再按当次换算率折成抽数（换算见 gacha-conversion）。

## 合成玉：其它来源
- **至纯源石兑换**：源石可以直接换合成玉，兑换率用 `get_prts_page(title="合成玉")` 或 `get_prts_page(title="至纯源石")` 现查。
- **基建「搓玉」**：制造站把固源岩或装置加工成源石碎片，贸易站的「源石订单」再把碎片换成合成玉。配方与耗时用 `get_item(name="源石碎片")` 查，贸易站侧的产出档位查 `get_prts_page(title="罗德岛基建/贸易站")`。长期占用制造站并吃龙门币，属于牺牲养成换抽数。
- **资质凭证区（绿票商店）**：有「合成玉」档位，单价与限购次数用 `get_prts_page(title="采购中心/凭证交易所", section="资质凭证区")` 查。
- **情报凭证区（紫票商店）**：复刻活动里重复获得的家具、时装会按比例转成情报凭证，每次补货的合成玉用 `get_prts_page(title="采购中心/凭证交易所", section="情报凭证区")` 查。紫票选项里合成玉的单位收益最高。
- 官方邮件、活动奖励、主线首通等也会给，但不是稳定周收入。

## 至纯源石
- 来源：采购中心充值、**首次通关获取**、活动获取、官方邮件赠送。
- 用途与代价（三档都要报，数值一律现查，历史版本调整过）：换合成玉、换理智、买时装；兑换率分别看 `合成玉` 页与 `至纯源石` 页，时装与专业强化包按件/按档计价，看时装商店与采购中心页面。
- 用 `ask_user` 让用户在「抽卡 / 刷本回理智 / 买时装」之间选，不要替他决定，并把三档代价都报出来。源石换抽是所有换法里最贵的。

## 龙门币
- 主要来源是资源收集里的「**货物运送**」关卡（代号 CE-x，如 CE-6），每周固定开放日（庆典等时期可能全开），推荐前先确认今天开不开。
- 每关的龙门币产出与作战消耗不要背，分两步现查：`get_stage(stage=…, include=["basic","drops"])` 给作战消耗与该关掉落；要企鹅物流口径的期望理智再用 `get_drop_rates(stage=…)`（只统计材料与道具掉率，不含龙门币产量本身）。产出档位表看 `get_prts_page(title="龙门币")`，该页标注「非实时更新，数据仅供参考」。
- 主线关卡也掉龙门币，但单位理智产出明显低于 CE 系列。缺龙门币优先刷 CE。
- 基建贸易站的「**贵金属订单（赤金订单）**」用赤金换龙门币，档位与耗时查 `get_prts_page(title="罗德岛基建/贸易站")`。
- 任务、签到、剿灭进度奖励、信用交易所也会给，但都是零散补充。
- 所有养成（精英化、专精、模组）都要龙门币，属于长期紧缺资源。**搓玉会直接吃龙门币并占用制造站**，PRTS 的说法是「搓玉会导致练度滞缓乃至停滞」，除非用户不再拉练度，否则不建议搓玉。

## 容易混淆的「信用」
- 信用是采购中心【信用交易所】的货币，不是凭证。来自每日结算（宿舍氛围、使用/被使用助战）与会客室线索交流。
- 每日结算的换算比例、信用上限与超限清空口径，用 `get_prts_page(title="信用")` 与 `get_prts_page(title="罗德岛基建/宿舍")` 现查；超过上限的部分会被清掉。
- 信用交易所商品每日刷新、数量有限，换什么先看游戏内页面（`screen-store`）。
