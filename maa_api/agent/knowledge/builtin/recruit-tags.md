事实来自 PRTS「公开招募」页（`get_prts_page(title="公开招募")`，该页分简介、计算器、TAG 组合、单 TAG、双 TAG 等节）。页面自己标注 TAG 组合表随客户端版本更新，所以**只有「资深/高级资深 + 时长拉满」这类规则是稳定的**，具体到某名干员的标签组合会变。

## 一次招募的消耗与前提
- 消耗 1 个招聘许可和一定的时间。**公开招募现在不再消耗龙门币**，网上的旧版龙门币对照表已经作废，不要照抄（具体以 PRTS 与游戏内为准）。
- 招聘许可的用途是「可从公开渠道招聘一位干员」，加急许可是立即完成招募；两者获得方式都是采购中心、任务奖励。
- 通关主题曲 0-2 后解锁公开招募；招募位数量与办公室等级挂钩，具体数量查 `get_prts_page(title="罗德岛基建/办公室")`，不要凭记忆报。
- 每次招募占用 1 个招募位。

## 标签怎么用
- 每个招募位给出若干标签，可勾选若干个（上限见 PRTS 该页）。标签只是「尝试圈定」范围，不是保证：招到的干员不满足某个已选标签时，该标签会被划掉（变灰并出现一条红线）。
- 稳定规则：**6★ 只能靠【高级资深干员】标签招到**；【资深干员】【高级资深干员】是稀有需求标签，会以黄色字体和特别的外观出现。
- 【资深干员】【高级资深干员】只有在**把招募时长拉满**时才开始招募才不会被划掉，从而必得 5★ / 6★；两个同时选时优先最高稀有度（即 6★）。「拉满」到底是哪一档、时长档位与稀有度下限的对应关系，查 `get_prts_page(title="公开招募")`，**不要凭记忆报某一时长对应哪几档稀有度**。
- 1★、2★ 干员只能通过公开招募获得；公开招募限定池里还有若干只能公招获得的干员（如 3★ 安德切尔、4★ 艾丝黛尔与清流、5★ 因陀罗与火神），名单随版本变化。
- 办公室的联络次数（也叫人脉、刷新次数）可以刷新当前这一轮的标签，但**恢复周期与持有上限不要凭记忆回答**：先查 `get_prts_page(title="罗德岛基建/办公室")`（页面的简介与计算器节）。办公室没有进驻干员时不会恢复；进驻非注意力涣散的干员会提高联络效率。达到上限后办公室内的干员会暂停工作（不再消耗心情）。

## 招募时长
- 时长范围与调节步长见 `get_prts_page(title="公开招募")`，不要照抄任何档位数字。
- 时长决定可能出现的稀有度下限；各档位对应的稀有度区间同样以该页为准。
- 想拿资深/高级资深的「必出」必须把时长拉满；两个标签都选了也一样，时长不到上限就会存在被划掉的可能。
- 因为已经不吃龙门币，拉满不会多花龙门币；本服务的 Recruit 任务默认就是把各档都设为时长上限（见 playbook-recruit）。

## 能稳定出高星的标签
- 【高级资深干员】+ 时长拉满 = 必出 6★。
- 【资深干员】+ 时长拉满 = 必出 5★。
- 只用普通标签时上限仍是 5★，但部分标签或组合能把范围压到全是 4★ 及以上（常说的「必出四星」）。哪些标签算「4★ 以上标签」、哪些组合成立，**以 PRTS 公开招募页的 TAG 组合表为准**，用 `search_prts` 或 `get_prts_page` 现查。
- **不要凭记忆报「某组合锁定某名五星/六星」**：该表随版本更新且可能有遗漏。要锁定具体干员时，让用户看游戏内的公开招募计算器或 PRTS 当期表格，你只保证上面几条规则。

## 招募过程中的两个按钮
- 使用加急许可可以立即完成招募。
- 「停止此次招募」会清除本次招募：不返还已投入的招聘许可/加急许可，也招不到干员。已经完成的招募再点停止，只会弹「太幸运了，招募提前结束」的提示，既不清除也不返还资源。
