## 等级与经验
- 升级同时消耗「作战记录」（提供经验）与龙门币，两种资源要一起备。
- 作战记录经验：基础 200、初级 400、中级 1000、高级 2000。除高级外都能在基建制造站生产。
- 每个精英阶段内部的经验与龙门币曲线不同，越到高等级越贵。以 6★ 为例：精英阶段 1 从 1 级到 80 级共需 337,000 经验、约 353,000 龙门币；精英阶段 2 从 1 级到 90 级共需 750,000 经验、约 745,000 龙门币（其它星级按各自的等级上限折算，见下一条）。精二后从 1 级拉到 90 级的这 745,000 龙门币，够再精二四名 6★ 干员（每名 180,000）。
- 星级对应的等级上限（精英阶段 0 / 1 / 2）：6★ 50 / 80 / 90；5★ 50 / 70 / 80；4★ 45 / 60 / 70；3★ 40 / 55 / 不能精二；2★ 与 1★ 只有 30 级、没有精一。

## 精英化（晋升）
- 精英化后等级回到 1 级，但面板数值不会重置。带来的效果：解锁更高的等级上限和技能等级上限；几乎所有干员都会扩大攻击范围；部分干员解锁新技能、新天赋或加强原有天赋；可能获得新的后勤技能。晋升到精英阶段 2 还可能解锁新立绘、新语音、新资料，以及模组系统。
- 龙门币是固定值：精一 6★ 30,000 / 5★ 20,000 / 4★ 15,000 / 3★ 10,000；精二 6★ 180,000 / 5★ 120,000 / 4★ 60,000（3★ 不能精二）。合计 6★ 210,000、5★ 140,000、4★ 75,000。
- 芯片按干员职业而不是星级：精一必须用对应职业的「芯片」；精二时 4★ 用对应职业的「芯片组」，5★/6★ 用对应职业的「双芯片」。双芯片在基建制造站用「2 个对应芯片组 + 1 个芯片助剂」合成（制造站 3 级，单份 1 秒）。芯片助剂在采购中心兑换：采购凭证 90 或高级凭证 15（见习任务、专业强化包等也会少量给，以游戏内为准）。
- 精英材料因干员而异，量级参考（龙门币见上，另计）：
  - 4★ 桃金娘：精一 先锋芯片 ×3 + 酮凝集 ×1 + 异铁 ×1；精二 先锋芯片组 ×5 + 研磨石 ×12 + 全新装置 ×8。
  - 5★ 德克萨斯：精一 先锋芯片 ×4 + 聚酸酯 ×5 + 异铁 ×3；精二 先锋双芯片 ×3 + 聚酸酯块 ×8 + 固源岩组 ×16。
  - 6★ 能天使：精一 狙击芯片 ×5 + 固源岩 ×12 + 酮凝集 ×4；精二 狙击双芯片 ×4 + 聚合剂 ×4 + 糖聚块 ×5。
- 精二的前置条件是精一满级（各星级精一满级见上表），且成本远高于精一。

## 技能等级与专精
- 技能升级用「技巧概要」：卷 1 用于 Rank 1~3，卷 2 用于 Rank 4~6，卷 3 用于 Rank 7 到专精三。
- Rank 7 之前，每次升级是该干员所有技能一起升；到 7 级之后每个技能要单独专精。专精只消耗技巧概要·卷 3 与中级/高级材料，不消耗龙门币和作战记录，但占用训练室并消耗真实时间。
- 技能等级上限由精英阶段决定：精 0 最高 4 级，精 1 最高 7 级，专精必须精英阶段 2。3★ 及以下最高只能到 7 级；4★ 及以上才能专一/专二/专三（游戏内写作 Rank Ⅰ/Ⅱ/Ⅲ，俗称 8/9/10 级）。
- 技能按精英阶段开放：技能 1 精 0 就有，技能 2 精 1 开放，技能 3 精 2 开放。3★ 通常只有 1 个技能，1★ 没有技能。
- 专精在基建【训练室】进行，基础耗时：专一 8 小时、专二 16 小时、专三 24 小时。训练室协助位放任意未处于涣散状态的干员再加 5% 速度：实际训练时间 = 基础时间 ÷ (1 + 0.05 + 协助干员的后勤技能加成)。
- 消耗量级（6★ 能天使的技能 3）：专一 技巧概要·卷 3 ×6 + 三水锰矿 ×4 + 全新装置 ×4；专二 技巧概要·卷 3 ×12 + 提纯源岩 ×4 + 五水研磨石 ×9；专三 技巧概要·卷 3 ×15 + D32 钢 ×6 + 聚酸酯块 ×6。材料因干员而异，不要把某个干员的清单套到另一个干员身上。

## 模组
- 解锁门槛：干员达到精英阶段 2 且等级 1 以上；只有 4★ 及以上稀有度有模组系统。
- 有专属模组的干员，精二后会自动装备一个没有效果的【基础模组】（俗称证章）。【专属模组】1 级只修改分支特性，2 级和 3 级在 1 级基础上强化天赋。一名干员同时只能装备一个模组。
- 解锁专属模组要完成该模组的解锁任务，并满足等级与信赖要求（例：4★ 桃金娘模组要 40 级、信赖 100；6★ 银灰模组要 60 级、信赖 100），再消耗材料。
- 消耗含「模组数据块」、龙门币和干员专属材料，数量随稀有度变化：4★ 桃金娘每级 1 个模组数据块，龙门币 2 万/2 万/3 万；6★ 银灰每级 4 个模组数据块，龙门币 8 万/10 万/12 万。
- 模组数据块在采购中心兑换（采购凭证 120 或高级凭证 20），也能从教学、任务、活动获得；升级用的「数据增补条」「数据增补仪」主要来自教学和保全派驻。
- 特限模组（特限证章）：不需要解锁任务，解锁与升级材料大幅减少（总计 3 个模组数据块），但升级仍要求信赖；强化效果只在特定玩法里生效，其它模式下只有数值加成。
- 优先级：队伍里精二干员不多时，先把资源给精二更多干员、提升等级和技能专精，收益大于开模组。

## 常见坑
- 精一后等级归 1 是正常现象，不是掉练度。
- 精二前先确认芯片/芯片组/双芯片是否齐，双芯片要提前在制造站合成。
- 专精不花龙门币，但占训练室、要排队等真实时间，训练位紧张时先排最需要的技能。
- 3★ 不能精二、不能专精；1★ 没有技能。
- 具体每级经验、龙门币与某位干员的材料清单，以游戏内和 PRTS「游戏数据基础」页、干员页为准。
