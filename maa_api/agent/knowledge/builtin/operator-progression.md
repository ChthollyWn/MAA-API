## 等级与经验
- 升级同时消耗「作战记录」（提供经验）与龙门币，两种资源要一起备。
- 作战记录分档，越高级给的经验越多，除最高档外都能在基建制造站生产；各档经验值与配方用 `get_item(name=…)` 或 `get_prts_page(title="罗德岛基建/制造站")` 查。
- 每个精英阶段内部的经验与龙门币曲线不同，越到高等级越贵。所以「从 1 级拉到满级要多少」不要凭记忆报：用 `plan_upgrade(targets=…)` 现算（它同时报出仓库缺口），或读 `get_operator(name=…, sections=["costs"])`。
- 星级对应的等级上限不一样，高星上限更高（精英阶段 0 / 1 / 2 各有上限）；上限表见 `get_prts_page(title="游戏数据基础")` 或 `get_operator(name=…, sections=["basic"])`。

## 精英化（晋升）
- 精英化后等级回到 1 级，但面板数值不会重置。带来的效果：解锁更高的等级上限和技能等级上限；几乎所有干员都会扩大攻击范围；部分干员解锁新技能、新天赋或加强原有天赋；可能获得新的后勤技能。晋升到精英阶段 2 还可能解锁新立绘、新语音、新资料，以及模组系统。
- 精英化消耗分两部分：**固定数额的龙门币**（只跟星级有关）与**该干员专属的材料**。数额与清单用 `get_operator(name=…, sections=["costs"])` 现查，`plan_upgrade` 会算出仓库缺口；不要拿别的干员的清单套。
- 芯片按干员职业而不是星级：精一必须用对应职业的「芯片」；精二时 4★ 用对应职业的「芯片组」，5★/6★ 用对应职业的「双芯片」。双芯片在基建制造站用「对应职业芯片组 + 芯片助剂」合成（有制造站等级要求），配方用 `get_item` 查。芯片助剂在采购中心兑换，单价用 `get_prts_page(title="采购中心/凭证交易所")` 取页内**采购凭证区**节查（该页正文按 section 分节，**节名随线上页面变动**：先不带 `section` 读一次，按关键词从返回的 `sections` 里挑中那一节，再带 `section` 取正文；见习任务、专业强化包等也会少量给，以游戏内为准）。
- 精英材料因干员而异，不要凭记忆列清单；同时精二的前置条件是精一满级，成本远高于精一。
- 要真的去练：先用 `plan_upgrade(targets=…)` 看缺口，再用 `start_upgrade_plan(name=…, targets=…)` 建计划交给 MAA 跑，进度和结果用 `list_upgrade_plans()` 查。

## 技能等级与专精
- 技能升级用「技巧概要」：低阶卷用于前期 Rank，高阶卷用于后期 Rank 与专精；哪一卷覆盖哪一段见 `get_prts_page(title="游戏数据基础")`。
- 到未专精的满级之前，每次升级是该干员所有技能一起升；满级之后每个技能要单独专精。专精只消耗技巧概要与中级/高级材料，不消耗龙门币和作战记录，但占用训练室并消耗真实时间。
- 技能等级上限由精英阶段决定：精 0 上限更低、精 1 更高，专精必须精英阶段 2；3★ 及以下只能升到未专精的满级，4★ 及以上才能专一/专二/专三。
- 技能按精英阶段开放：技能 1 精 0 就有，技能 2 精 1 开放，技能 3 精 2 开放。3★ 通常只有 1 个技能，1★ 没有技能。
- 专精在基建【训练室】进行，有基础耗时（专一 < 专二 < 专三）；协助位放干员能按协助干员的后勤技能加成缩短用时。基础耗时与公式见 `get_prts_page(title="罗德岛基建/训练室")`。
- 专精材料因干员与技能而异，用 `get_operator(name=…, sections=["skills"])` 查清单，不要把某个干员的清单套到另一个干员身上。

## 模组
- 解锁门槛：干员达到精英阶段 2 且等级 1 以上；只有 4★ 及以上稀有度有模组系统。
- 有专属模组的干员，精二后会自动装备一个没有效果的【基础模组】（俗称证章）。【专属模组】1 级只修改分支特性，2 级和 3 级在 1 级基础上强化天赋。一名干员同时只能装备一个模组。
- 解锁专属模组要完成该模组的解锁任务，并满足等级与信赖要求，再消耗材料；门槛与消耗用 `get_operator(name=…, sections=["modules"])` 现查，PRTS 侧汇总在 `干员模组一览`。
- 消耗含「模组数据块」、龙门币和干员专属材料，数量随稀有度与模组等级变化，别凭记忆报。
- 模组数据块在采购中心兑换（采购凭证或高级凭证，单价见 `采购中心/凭证交易所` 各 section），也能从教学、任务、活动获得；升级用的「数据增补条」「数据增补仪」主要来自教学和保全派驻。
- 特限模组（特限证章）：不需要解锁任务，解锁与升级材料大幅减少，但升级仍要求信赖；强化效果只在特定玩法里生效，其它模式下只有数值加成。
- 优先级：队伍里精二干员不多时，先把资源给精二更多干员、提升等级和技能专精，收益大于开模组。

## 常见坑
- 精一后等级归 1 是正常现象，不是掉练度。
- 精二前先确认芯片/芯片组/双芯片是否齐，双芯片要提前在制造站合成。
- 专精不花龙门币，但占训练室、要排队等真实时间，训练位紧张时先排最需要的技能。
- 3★ 不能精二、不能专精；1★ 没有技能。
- 具体每级经验、龙门币与某位干员的材料清单，以游戏内和 PRTS「游戏数据基础」页、干员页为准；本服务里先 `plan_upgrade` 再报数。
