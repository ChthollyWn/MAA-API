## 进入与关卡分类
- 作战入口在首页中央的「终端」按钮里（见 screen-home），点进去才是关卡选择界面。
- 关卡分类用 PRTS 的叫法：主题曲（主线）、插曲与别传（SideStory，现并入「曲谱」）、资源收集（原「物资筹备」+「芯片搜索」）、常态事务（剿灭作战、保全派驻）、长期探索（集成战略、生息演算）、周期挑战（危机合约、矢量突破、全息作战矩阵）、悖论模拟、训练场。
- 曲谱界面有两个可用的锚点：右上角的「乐章收录」按钮进入章节总览；进入某个章节后画面底部是章节切换标签，可在乐章内快速换章。
- 悖论模拟不在作战列表里：从干员档案页进入，或在干员列表右上角的排序里选「悖论模拟」筛选。训练场要通关主题曲 3-8，再从「档案 - 训练场」进入。
- 分类页签/列表本身在画面上方还是左侧、占多少比例，**需截图确认**；认字（主题曲、资源收集、常态事务…）比认坐标可靠。
- 大部分常驻内容要先通关指定主线关卡才解锁（基建要 0-11、公开招募要 0-2），点不动就先看解锁条件。

## 剿灭作战界面
- 里面分「当期委托」「长期剿灭委托」「剿灭战模拟」，过期的进「假定作战目标」，另有「剿灭战模拟预告」。
- 选哪张图、每周上限怎么涨，见 annihilation-weekly；这里只提醒一点：关卡选择界面上每个关卡旁边的小数字是**这一关要花的理智**，不是剩余理智，报数前先确认读的是哪一个。

## 理智、开始行动、代理指挥
- 理智可以在「作战关卡选择」右上角随时确认（首页的读法见 screen-home，机制见 sanity-system）。
- 「开始行动」按钮和「代理指挥」开关都在关卡的出战确认区域；两者的具体位置**需截图确认**。代理指挥的解锁条件与翻车原因见 stage-rules。
- 剿灭作战与保全派驻另有「全权委托代理指挥」：消耗 1 张常态事务代理卡和理智，跳过作战并立即结算（按最高歼灭数给报酬、不增加信赖；本次合成玉为 0 时用不了）。

## 交给本服务时
- Fight 任务的 `stage` 直接写关卡名，写法与选择策略见 playbook-sanity-planning；剿灭作战必须写 `Annihilation`。
- 关卡处于分阶段开放中（见 event-and-rerun）或用户自己都点不进去时，先说明情况，别硬跑。
- 用户只说「刷活动本」「刷那个新图」时，先问清是哪一关，不要凭印象填关卡号。
