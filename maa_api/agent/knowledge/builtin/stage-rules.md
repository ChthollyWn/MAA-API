## 关卡评价（星级）
- 歼灭关卡内所有敌人且目标生命值一点没掉：3 星（完美通关）；突袭模式记为 4 星。
- 有漏怪但目标生命值还剩至少 1 点：2 星，仍算过关。
- 目标生命值归零：行动失败。
- 拿至纯源石必须至少 3 星；2 星虽然过关，但拿不到首通源石，而且素材奖励数量会下降，极端情况下为 0。

## 理智与失败
- 理智在进入关卡时就扣，不是结算才扣。
- 现在作战失败或中途退出关卡都会返还全部理智，普通与突袭一样，不要再对用户说「只有第一次失败才返还」。
- 博士经验（声望）：每消耗理智都会得到声望，三星通关与剿灭作战给得更多；具体比率以页面为准，不要报记忆里的旧值。

## 演习
- 演习不消耗理智也不给报酬；现在可以做无限次演习——**是否还消耗演习券按版本查证**（`get_prts_page(title="关卡一览")`），不要凭记忆说「演习要花券」。
- 用户没把握、只是想试阵容时提演习，不要直接让他烧理智。

## 代理指挥（自动部署）
- 开启条件：不使用好友助战干员、3 星通关该关卡，即解锁这关的代理指挥；首次解锁会自动保存一份阵容与操作记录。
- 代理复刻的是「最近一次保存」的操作序列；干员练度、技能、模组变化，以及丢帧、版本更新都可能让代理翻车，所以「以前能过」不等于「现在能过」。（代理是按固定随机序列重放的机制推断，PRTS 没有明文，别当结论讲给用户。）
- 倍战（连续代理）：代理指挥可以把同一关连续打多次，连战上限在版本更新中调整过，**当前上限查 `get_prts_page(title="关卡一览")`**。
- 倍战只对主题曲、资源收集和正在开放的限时活动关卡生效；插曲、别传不支持。
- 接管代理、代理失误或作战失败时会缩回单次消耗与掉落。
- 对应到本服务：Fight 的 `series` 就是连战次数，`-1` 禁用切换、`0` 让内核自动选当前可用的最大次数、`1`~`6` 指定次数。传 `0` 最省心；本服务目前只开放到 6，游戏内上限已经更高，超出部分以游戏内为准。

## 突袭模式（含更高难度版本）
- 消耗与普通相同：同一关的普通与突袭理智消耗一致；要报数值就 `get_stage("<关卡代号>")` 读 `sanity`，遇到个例以关卡页为准。
- 难度：突袭有附加条件（如部署费用自然回复速度减半、近战单位攻击力减半、可部署单位上限减少），同时敌方属性提升；`get_stage` 的 `challenge_condition` 是该关附加条件、`has_challenge` 表示有无突袭，要报就照返回值讲。
- 奖励：突袭首次 3 星通关同样给至纯源石，与普通首通分开计算；部分关卡还额外给家具等首通道具。
- `get_stage` 的 `challenge_practice_sanity` 只是关卡页的历史演习消耗字段，演习已不限次也不消耗演习券，**不要拿它当限制条件**。
- 判断某关突袭打没打过，看游戏内对应首通奖励是否已领取，不要凭对话记忆下结论。
- 在本服务切换难度：Fight 的 `stage` 在关卡编号结尾加 `Normal` / `Hard`（例：`CE-6Hard`）。

## 首次通关与推荐等级
- 首次 3 星通关该关卡给至纯源石（突袭版本另算一份），部分关卡还首次给干员招聘合同或家具；首次掉落只拿一次，不参与长期刷图收益比较。
- 每个关卡都标了推荐等级，形如 `LV.10` 或 `精英1 LV.50`，**要用就用 `get_stage` 的 `recommend_level` 字段**，不要照抄举例值。
- 它只是关卡给出的练度参考，不是硬性门槛。报给用户时说明这是推荐值，不要因为用户练度低于推荐等级就断言打不过，也不要拿它当准入条件。
