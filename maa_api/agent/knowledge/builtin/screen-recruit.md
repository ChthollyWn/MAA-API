**本条目不给像素或百分比坐标**：游戏界面的具体布局在 PRTS 上没有依据，凭记忆写数字会点错。下面只给相对位置，用之前先 get_screenshot，按「像素 = 比例 × 截图 width / height」自行量取，并把量到的值写进回复。

## 大致位置
- 整个公开招募是一块覆盖首页的面板，大致中部是标签区：5 个标签以图标＋文字的方块排列。黄字、外观特别的那两个就是【资深干员】【高级资深干员】（见 recruit-tags）。
- 招募位：大致在面板上方或左侧，共 1~4 个；没解锁的位置需要升级基建办公室（见 infrast-mechanics），提示文案与位置以截图为准。
- 时长选择：大致在标签区下方靠左，是档位按钮加滑动条的组合，最小调节单位 10 分钟——具体有哪几个档位以截图为准，别照抄任何档位数字。
- 开始招募按钮：大致在面板右下角，通常与「停止此次招募」相邻。
- 结算弹窗：招募完成或使用加急许可后大致在屏幕中央弹出，显示招到的干员与稀有度，需要点一次确认关闭；弹窗不关会挡住后续操作。
- 刷新标签的入口就在公招面板上，消耗办公室攒下的联络次数；按钮的准确位置和可用条件需要截图确认。

## 操作流程
1. 用 Recruit 任务（times=0）只进入公招页不招募，或手动从首页进入；进入后等约 1~2 秒再截图，避免截到转场。
2. get_screenshot，先只读不点，把 5 个标签原样报给用户，并指出有没有资深/高级资深。
3. 需要点击时，写清你要点的元素和量到的坐标；点击属于原子操作，第一次会弹出会话授权确认，先告诉用户。
4. 每次点击后重新截图确认状态变化（被划掉的标签会变灰并出现一条红线），不要连点。
5. 改时长要点档位按钮或拖动滑动条；这一步只有手动操作时才需要，用 Recruit 任务时由内核按 `recruitment_time` 自动设置。
6. 用户问结果就读结算弹窗；读不清就说读不清，不要猜干员名。

## 需要截图确认的内容
- 标签区、时长区、开始招募按钮的实际占屏比例，以及弹窗的确认按钮位置。
- 招募位数量与当前处于「招募中」的是哪几个位置。
- 不同客户端版本和首页主题下标题文案、按钮名称可能有差异，以截图实际文字为准。
