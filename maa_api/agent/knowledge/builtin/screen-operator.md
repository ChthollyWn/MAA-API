位置一律按占截图宽、高的比例表示，像素坐标 = 比例 × get_screenshot 返回的 width / height。

**先说清楚可靠性**：PRTS 没有收录干员列表与详情页的界面坐标，能查到的只有「详情页里有哪些信息、哪些元素可点」。所以下面除了明确写了比例的地方，**所有位置都必须先 get_screenshot 现场确认，不要凭记忆点击**。本站唯一相关的图是 2022 年上传的「新手入门 属性面板.png」，那只是属性区的局部放大图（669×231），既不是整屏、也与当前版本可能不同，不能用来推算任何坐标。

## 干员列表
- 入口位置：不确定。从首页进入干员界面的按钮位置需要截图确认（首页已确认的只有顶栏货币、终端里的理智、右下角仓库入口，见 screen-home）。
- 列表里的筛选/排序入口：不确定，需要截图确认。用户要「找某职业/某稀有度的干员」时，先截图看清筛选控件再点，不要连点。
- 干员一览在 PRTS 网页端支持按职业、分支、稀有度筛选，但那是网页功能，跟游戏内列表不是一回事，不能据此推断游戏内控件位置。

## 干员详情页
PRTS《新人入门》旧版（2020-06-09 修订）逐条说明过这个页面，当前版本页面已改写成养成指南，所以**下面只保证「详情页里有这些信息」，不保证它们今天的位置**：
- 基础属性：生命上限、攻击、防御、法术抗性、再部署、部署费用、阻挡数、攻击速度。默认只显示图标和数值，点击该区域会展开详细说明。
- 信赖：默认显示信赖值条，点击可以看信赖加成的具体数值。
- 职业图标与攻击范围：点击职业图标会弹出八大职业的简介；攻击范围图里实心方格是干员自身所在格。
- 部署位与标签：说明这名干员能放高台还是地面、能做什么。
- 等级与经验值：点击可以给干员喂作战记录来升级。
- 精英阶段：点击进入精英化界面，界面里会说明这次精英化的影响和需要的材料，并执行晋升。
- 潜能等级：点击进入潜能培养界面，可以看每级潜能的差异并提升潜能。
- 技能与技能等级：点击进入技能详情界面，可以看这名干员的技能、设置默认技能、升级技能。
- 特性、天赋（点击看详情）、代号与星级、资料按钮、换装按钮。

## 已确认的交互规则（与位置无关，来自当前版 PRTS 新人入门）
- 技能：属性页面里标有蓝底白色 √ 的是默认技能，新编入队伍时会自动选中；修改默认技能不影响已经编入队伍的携带状态。干员出战时只能带其中一个技能，编队时可在左侧边栏下方改成本次行动实际携带的技能。
- 模组：属性页面中被选中的模组是默认装备的模组，新编入队伍时自动选中；干员同时只能装备一个模组。编入队伍时可以把左侧边栏中部的页签切到「分支+」，改成本次行动实际携带的模组。
- 模组的解锁任务、解锁所需的等级与信赖要求会显示在模组相关的界面上（PRTS 的模组数据里逐条记录了「任务1/任务2」与解锁等级、信赖），但入口和排版位置需要截图确认。

## 安全操作流程
1. 先 back_to_home（见 screen-home 回首页），再 get_screenshot，记下 width / height。
2. 找不到目标控件时，放大关注区域再截图对比；不要靠记忆连点，也不要一屏内连点两次以上。
3. click / swipe 属于原子操作，本会话第一次会弹出授权确认，先告诉用户。
4. 每次点击后等 1~2 秒再 get_screenshot，确认真的进了目标界面，再继续下一步。
5. 走错界面就 back_to_home 重来，不要盲点返回键。
6. 需要读干员详情页上的数字（等级、精英阶段、技能等级、材料数量）时，读完先在回复里写出来，再做下一步，方便用户核对。

## 需要截图确认、不要凭记忆做的判断
- 干员列表入口、列表的筛选/排序入口、列表滚动方式。
- 详情页上等级/精英阶段/潜能/技能/信赖/天赋各区块的具体坐标。
- 精英化按钮、技能升级按钮、模组解锁/升级入口的坐标。
- 界面里出现「停止招募」「确认消耗」这类不可逆按钮时，先向用户复述后果再点。
