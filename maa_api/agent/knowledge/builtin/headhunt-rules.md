## 基础概率（每一抽）
- 6★、5★、4★、3★ 各有基础概率（四档之和就是全部）。百分比用 `get_prts_page(title="寻访规则")` 现查，别凭记忆报。
- 这是**基础**概率，受下面「概率提升」影响后实际值会变；没有池种改过基础概率。

## 六星概率提升（俗称保底、垫抽、水位）
- **标准寻访**里连续若干次没出 6★ 后，概率逐次递增直到必定获得；起提抽数、初始增幅、每次增量都从 `寻访规则` 现查，别背「抽到多少次加多少」。
- 计数**跨池继承**：标准寻访里没出 6★ 都会累计、池子结束不清零，累计的概率也带进下一个标准寻访；出了 6★ 就立刻回到基础值。
- **中坚寻访**有自己的一套计数，只对【中坚寻访】生效。
- **限定、联动、归航寻访与【跨年欢庆·中坚寻访】**：计数**不跨池、不继承**，池子结束清零。普通【跨年欢庆寻访】的计次规则 PRTS 没写明，以游戏内为准。
- 各池种计次互相独立：标准、限定、联动、归航各自累计。

## 每个池子的首次十连保底
- 「新寻访特惠」：每个新寻访池**头几次寻访内必得一名 5★ 或以上干员**，每池限一次；抽数见 `寻访规则`。
- 这是池级保底，和六星计数是两回事；新池开了先看它还在不在。

## 额外的抽取保底
- 常驻标准寻访「**标准选调**」：累计到第一档后，下一个 6★ 必为当期 UP 的 6★ **之一**；到第二档后，下一个 6★ 必为 UP 的**另一名**。各条件当期仅生效一次，池子结束清零；两档阈值见 `寻访规则`。
- 限时标准寻访「**定向选调**」：连续若干次没出该池 UP 的 6★ 时，下一个 6★ 必为该 UP 干员，当期仅一次、池子结束清零；中途出了 6★（哪怕不是 UP）计数清零但不算保底生效。阈值见 `寻访规则`。
- 限定寻访「**必得赠送**」：累计到阈值后额外赠送一份当期限定干员简历，仅一次、需手动领。属额外赠送而非寻访获得，不产数据契约、也不影响下一个 6★ 的概率；计数本期结束清零。
- 限定寻访的**数据契约**：每次寻访都会累积一张寻访数据契约；攒到兑换当期 6★ 招聘合同的门槛、或换 5★ 合同的较低门槛都能换，次数不限。门槛与关闭后转寻访参数模型的比例用 `get_prts_page(title="采购中心/凭证交易所")` 取页内**寻访数据契约交换所**节现查（该页正文按 section 分节，**节名随线上页面变动**：先不带 `section` 读一次，按关键词从返回的 `sections` 里挑中那一节，再带 `section` 取正文；参数模型不过期）。
- 联动寻访有硬保底、新年特别十连在池内必得 6★，抽数以游戏内为准。

## 抽一次要花多少
- 单次与十连各要多少合成玉，用 `get_prts_page(title="寻访规则")` 或 `get_prts_page(title="合成玉")` 现查，别凭记忆报价；换算见 gacha-conversion。
- 有凭证时优先消耗凭证；十连时凭证、合成玉、源石按固定优先级自动混用。
- 新人特惠单次价格低于常规池，抽取次数有限（含教程必抽一次），用完该池永久关闭；价格与次数看游戏内界面。

## 卡池类型
- **标准寻访**：最基础的池。常驻版按周期轮换（见 `寻访规则`），若干名 6★ 与 5★ 出率提升，其中一名 6★ 与一名 5★ 同时进【高级凭证区】；限时版随活动推新干员。标准寻访的干员除特殊说明外，也能在中坚以外的所有寻访中获得。
- **中坚寻访**：最早一批 6★/5★ 移出标准与限定寻访后加入的池。常驻版按周期轮换、与同期标准错开，干员池每年更新。中坚寻访与通用凭证区适用「中坚获取规则」，只产通用凭证与中坚信物，**不与标准规则互通**。
- **限定寻访**：分【春节】【庆典】【夏季】三类，各自限时开放。同类限定干员以后会在同类池再登场，可用数据契约兑换；限定干员不进任何标准寻访，限定池不复刻。
- **特殊寻访**：新人特惠（开头若干抽必出 5★ 以上）、跨年欢庆（首次获得的 6★ 必是此前没获得过的）、新年特别十连、联动、归航（针对长期未登录的博士）。
- 当期有哪些池、起止时间与 UP 干员用 `get_gacha_pools` 查，报完让用户以游戏内为准。

## 凭证能不能通用
- 寻访凭证 / 十连寻访凭证：**通用**，常规池都能用。
- 中坚寻访凭证 / 十连中坚凭证：PRTS 标注「**仅可用于【中坚寻访】**」。
- 限定、联动、新年等特殊池的凭证与抽取限制会随版本变，以游戏内为准，别凭记忆回答。

## 回答用户时的纪律
- 当期卡池名、UP 干员、起止时间都先 `get_gacha_pools` 现查。
- 报概率与门槛时，从 `寻访规则` 读到的数值要连「截至何时」一起交代；没写就说不确定。
- 不要预测「再抽多少发能出」；只讲保底机制与概率，不给「必出」的承诺。
- 用户问「要不要抽」时，先报清楚：还差多少抽到硬保底、这池计数出六星会不会清零、凭证够不够。
- 概率与规则都是**国服**口径，外服可能尚未实装或数值不同，外服用户以游戏内页面与官方公告为准。
