# M12 MCP Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 MAA-API 交付可供外部客户端调用的 Streamable HTTP MCP 服务和动态 stdio 瘦代理。

**Architecture:** FastAPI 主进程挂载 MCP server 并持有唯一 ToolRegistry、ConfirmationService 与 MaaCore 所有权。stdio 子进程只从主服务读取工具 schema，并通过 MCP 专用 REST invoke 路由转发；所有 MCP 调用共享确认和审计路径。

**Tech Stack:** FastAPI / Starlette、官方 MCP Python SDK (`mcp==1.13.1`)、Pydantic、SQLModel / Alembic、HTTPX、React / TypeScript。

**Spec:** [2026-09-25-m12-mcp-server.md](../specs/2026-09-25-m12-mcp-server.md)

## Global Constraints

- MCP Streamable HTTP 挂载路径为 `/mcp`，宿主 FastAPI lifespan 显式进入并退出 `session_manager.run()`。
- HTTP transport 使用 SDK 低层 `mcp.server.Server` 和 `StreamableHTTPSessionManager`；工具列表必须逐请求读取 query scopes，不能使用 FastMCP 静态 tools/list。
- 默认 scope 为 `status,pipeline,device,schedule,confirmation`；`raw`、`resource`、`ops` 需显式开启。
- scope 同时筛选工具列表并约束工具调用，但它不是授权边界。
- MCP HTTP 在鉴权开启时每个请求只使用 Bearer token；缺失/无效凭据复用 `UNAUTHORIZED` 与失败限流；`Mcp-Session-Id` 只关联 session，不作为凭据。
- Host 校验默认允许 loopback 和本机 RFC1918 LAN IPv4，SDK pattern 用 `host:*`；Host 对应的 HTTP/HTTPS Origin pattern 同步配置；显式配置只允许 loopback/RFC1918 IPv4，不允许 FQDN。
- stdio 代理必须经 HTTP 调用主进程，不创建 MaaCore、数据库连接或第二个 ToolRegistry。
- stdio 工具 schema 从 `GET /api/agent/tools` 动态读取；调用走 `POST /api/agent/mcp/tools/{name}/invoke`。
- `agent_audit.scopes` 为 nullable JSON 字符串列表；非 MCP 与历史调用保持 null。
- 所有工具仍经应用服务层；M12 不实现 LLM 循环、会话消息写入或 Copilot 运行器。
- 超过 25 秒仍待确认的 MCP 调用返回 pending，随后由 `check_confirmation` 查询；禁止自动重放。
- 新配置 `mcp.allowed_hosts` 仅从 YAML / 环境变量读取，标记只读且重启生效。

## 已裁定事项

- **Ruling:** 将 `confirmation` 加入默认 scope — 用户确认；保证 25 秒 pending 返回后，默认接入即可调用只读 `check_confirmation`；若错误，代价是默认工具清单比旧文档增加一个只读工具。
- **Ruling:** stdio 使用受保护的 MCP 专用 invoke API 并记录 `caller=MCP` 与代理 scope — 用户确认；保留 REST 动态 schema source 与准确审计归属；若错误，代价是新增一个对外可见 API operation 需要后续兼容维护。
- **Ruling:** M12 Host 验收限本机和局域网，任意 Tailscale FQDN 部署验收留 M15 — 用户确认；与 M15 部署范围一致；若错误，代价是外部客户端需等待 M15 才能用 FQDN 接入。
- **Ruling:** `scopes` 只控制 MCP 工具可见性和调用一致性，不作为授权 — 遵从 README/ADR-06；若错误，代价是有效 token 仍能请求更宽 scope。
- **Ruling:** HTTP transport 使用缓存可验证的官方 SDK `mcp==1.13.1` 低层 `Server`，不使用 FastMCP — 本机源码确认只有低层 request handlers 能按每个请求的 query scopes 动态生成 `tools/list`；FastMCP 固定全局列表会产生跨 session scope 串用。网络不可用，因此没有声称这是上游最新版；若错误，代价是后续 SDK 升级时需要适配 API。
