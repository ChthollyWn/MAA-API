## 验收

1. `.venv/bin/python -m pytest -o addopts= -q`：仅剩既有的两条长期已知红（`tests/services/test_activity_index.py` 真资源用例）。
2. 四处生成物 `--check` 全绿：`scripts/dump_openapi.py`、`scripts/generate_api_guide.py`、`web/pnpm gen:api:check`、`scripts/copy_inventory.py`（定稿后重设基线）。
3. 前端 `pnpm typecheck` / `pnpm vitest run` / `pnpm build`（末行 `[sw_harness] SERVICE WORKER OK`）；`scripts/agent_smoke.py`、`scripts/frontend_smoke.py` 末行 `SMOKE OK`。
4. 真机整轮数据写进 `docs/13-决策记录.md` 的 M38 小节（§8.53）与台账。

## 风险与回退

- 层配置生成失败：只记 WARNING，启动照旧（内核退回默认 500，功能不受影响）。
- `postDelay` 压缩导致偶发点不动/翻不动：把 `CLICK_POST_DELAY` / `BACK` 节点 `postDelay` / `SWIPE` 节点 `postDelay` 各自还原，只保留链合并与短路。
- 提速不达预期：设置可调回 500，编排改动可单独回退，二者互不依赖。
