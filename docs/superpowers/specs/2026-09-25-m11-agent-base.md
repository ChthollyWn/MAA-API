# M11 Agent 基座规格与验收简报

> **后续范围说明（2026-09-25）：** 本文是 M11 历史规格。原文涉及 MCP 调用方、25 秒 helper 与 M12 传输的设计已由 [docs/13 §8.4](../../13-决策记录.md) 撤销；当前范围保留 REST 工具基座与内置 Agent，不要据此恢复 MCP 功能。

## 范围与非目标

M11 从 `refactor/v2` 建立 `m11-agent-base`，交付 ToolRegistry、所有当前可执行工具的 REST API、风险策略、确认/授权/审计、会话 CRUD 与消息只读查询、确认卡片和审计页。Copilot 作业支持校验上传与列表；执行器因 MaaCore 尚无作业调用服务或引用参数而暂缓，不得改用普通 Fight 代替。MCP 传输归 M12；LLM 循环、会话 `POST /messages`、授权状态常驻提示归 M13。

## 硬约束

- 工具只能调用应用服务；不直接访问 `CoreClient`，不开放任意 `adb shell`；沿用单 `access_token` 鉴权。
- `stop_pipeline`、`trigger_screencap`、`back_to_home`、已校验保存的 `upload_copilot`、`delete_schedule` 及只读工具免确认。其它原子操作：有效 `internal` 会话按授权执行；REST/MCP 无内部会话，每次确认。非法内部会话 fail closed。
- 授权默认 15 分钟、最多 60 分钟；确认默认 10 分钟，授权确认 120 秒。服务启动、关闭及会话关闭/切换/删除时清除或撤销授权。
- REST `async` 确认返回 202；详情终态包括执行状态、结果或错误、`audit_id`。REST `sync` 等待完成；共享 MCP helper 最多短等 25 秒，M12 负责传输。
- Agent 审计以 `request_id` 关联，单行仅从 PENDING 转到一次终态；REST `Idempotency-Key` 1–64 字符、保留 24 小时，键与 body 不匹配返回 409。
- 已批准但结果未落审计、或直接异步调用仍处于 PENDING 时，重启/关闭标记执行结果不确定并禁止重放；`check_confirmation` 只读结果。
- 完成后只 `--no-ff` 合回 `refactor/v2` 并打 `v2-m11`；不 push、不合入 `dev`、不使用 worktree。

## 需先验证的假设

验证 M5/M6 应用服务能支撑已交付工具；自定义 task schema、资源目录写入、MaaCore reload 失败回滚与并发操作安全。必须用本地 Copilot/SSS、基建方案及 `tasks.json` 资产作结构检查。目标视觉模型能力由用户确认；本轮因环境无 LLM 端点和 ADB daemon 权限，截图理解与真机流程仅记为补充检查。

## 硬验收命令

```bash
.venv/bin/python -m pytest -q
.venv/bin/python scripts/agent_smoke.py
.venv/bin/python scripts/api_smoke.py
.venv/bin/python scripts/dump_openapi.py --check
cd web && pnpm install --frozen-lockfile && pnpm gen:api:check && pnpm typecheck && pnpm test --run && pnpm build
.venv/bin/python scripts/frontend_smoke.py
.venv/bin/python scripts/generate_api_guide.py --check
```

`agent_smoke.py` 必须不依赖真机，覆盖 REST 工具调用、确认往返、会话授权复用、审计回查和自定义 task reload 失败回滚，并以 `SMOKE OK` 收尾。真实 MaaCore/Android 与视觉模型检查只记录结果；补充命令：`DYLD_LIBRARY_PATH=$PWD/resource/lib/maa/Darwin .venv/bin/python scripts/core_smoke.py`。
